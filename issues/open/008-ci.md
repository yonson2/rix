# [008] CI on GitHub Actions - fmt, clippy, tests, build

**Status:** open
**Milestone:** M0
**Depends on:** [007]
**Created:** 2026-11-02
**Closed:** -

## Problem
Nothing checks a push. A broken build or a clippy regression is found only on the next
local build.

## Approach
`.github/workflows/ci.yml` on push and PR: `cargo fmt --check`, `cargo clippy --all-targets
-- -D warnings`, `cargo test`, on ubuntu with Bevy's Linux deps (libasound2-dev,
libudev-dev, libwayland-dev, libxkbcommon-dev) and a cargo cache. Take the shape from
bevy_new_2d's CI ([026] research). Later steps add mobile cross-compile checks
(`cargo build --target aarch64-linux-android` via cargo-ndk, `aarch64-apple-ios` on a
macOS runner).

## Verification
A push to the GitHub remote shows a green run.

# [021] Android build on main

**Status:** open
**Milestone:** M2
**Depends on:** [018]
**Created:** 2026-11-02
**Closed:** -

## Problem
Android only exists on `feat/android` (4 commits, 3 behind main, last "some android shit").
The branch was generated by `setup_android.sh` from Bevy 0.15.3's `examples/mobile`
Android project and commits build outputs: `app/src/main/jniLibs/arm64-v8a/librix.so`
(73 MB, debug), `.gradle/`, `.idea/`, `app/.cxx/`, `local.properties`.

## Approach
Port it to main on Bevy 0.20: an Android project under `mobile/android/` based on Bevy
0.20's own `examples/mobile/android_example` (Gradle, AGP and `games-activity` versions
matching the `android-activity` crate Bevy 0.20 uses), `cargo-ndk` building the `.so` into
`jniLibs` at build time (never committed), `just android` and `just android-release`
recipes. `src/lib.rs` gets the `#[bevy_main]` entry, `main.rs` stays a thin desktop
binary, `crate-type = ["rlib", "cdylib"]` (plus `staticlib` for iOS if [020] needs it).
Application id from [010] Q2 (branch: `org.pp.rix`).

## Verification
`just android` builds an APK that installs on the `Medium_Phone_API_36` emulator
(arm64); `git ls-files mobile/android | grep -E '\.so$|\.gradle/|\.cxx/'` is empty.

## Notes
- Running without the crash is [022].

  `Medium_Phone_API_36`, `Pixel`, `ketania`; `adb`/`emulator` are not on PATH (use
  `~/Library/Android/sdk/platform-tools/adb` and `.../emulator/emulator`).

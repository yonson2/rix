# [042] Sound effects set

**Status:** done
**Milestone:** M4
**Depends on:** [041], [011]
**Created:** 2026-11-02
**Closed:** 2026-11-03

## Problem
No sound effects exist.

## Approach
One set in the chosen style ([011] Q4): line start, line tick while drawing, claim, eat,
bomb, enemy bounce (rate-limited), death, level clear, UI tap. Small `.ogg` files; a
tracked source sheet (prompt or synth params) per file so any sound can be regenerated.

## Verification
Every event above plays its sound in a manual run; total SFX size in Notes.

## Notes
- [011] Q4 (2026-11-02): generate our own SFX, as in Ketania (`tools/elevenlabs.py`).
- Done 2026-11-03. Nine sounds from ElevenLabs Sound Effects (`eleven_text_to_sound_v2`,
  Creator plan: commercial licence), three takes each with `tools/elevenlabs.py sfx`
  (the sfx part of Ketania's tool), about 300 credits. Picked by measurement, not by ear
  (an instant start, little dead tail, room in the level for many sounds at once); Pedro
  can re-pick by ear: the takes stay in `audio-src/takes/sfx/` (gitignored). Each master and
  its request sit in `audio-src/sfx/` (1.7 MB WAV); the encode trims the trailing silence
  (not the hum loop), sets a peak per sound (hum -16 dB, bounce -10, tap -8, line start -6,
  others -1 to -3 dB) and runs `oggenc -q 5`. Sources sheet: `audio-src/sources.md`.
- Hooks: `Sfx` event (`Claim` in `polygon.rs`, `Eat` in `on_despawn_enemy`, `Bomb` in
  `basic_bomb::activate`, `Bounce` in the ball collision, at most one per 80 ms); the
  death and the level clear play on their state entry; the line plays `line_start`, then
  loops `line_hum` while a `TempLineSegment` exists and the game runs. A bomb kill plays the
  bomb and the eat sound together. No line tick: the hum covers it.
- **Total SFX size: 208 KB** (9 `.ogg` files, 8 KB to 44 KB).
- Verified: shot runs log "audio: ... starts" for claim, line start, hum, death, level
  clear, tap and bounce (seeds 2, 5, 8); the Android emulator plays the same set over four
  scripted games without a crash; eat and bomb are pinned in the kill and bomb tests (the
  scripted games die before level 2). `just replay` hashes and the `just shot` image are
  unchanged. The by-ear manual run is Pedro's.

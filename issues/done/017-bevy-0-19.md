## Notes
- Done: bevy 0.19.1, avian2d 0.7.0. Lock: winit 0.30.9 and objc2 0.5.2 (override stays;
  wgpu 29 adds objc2 0.6.5 for Metal), android-activity still 0.6.0, wgpu 29.0.4, glam
  0.32.1, parry2d 0.27.0. Android findings for [021] are in its Notes.
- Applied: `crt.rs` render-graph node -> a `Core2d` system `post_process` in
  `Core2dSystems::PostProcess`, `.after(tonemapping).after(smaa)` (`ViewQuery`,
  `RenderContext` param, `multiview_mask: None`); `Hdr` from `bevy::camera`; `TextFont`
  takes `font: handle.into()` and `FontSize::Px(..)` (ui, game over, menu, item
  countdown); `Assets::get_mut` returns `AssetMut`, bound `mut` (6 sites);
  `SystemCondition::and` -> `and_then` (ui.rs, same short-circuit).
- CRT order: 0.18 had no edge between CRT and SMAA. Shots with CRT before and after SMAA
  differ by PSNR 54 dB (no visible change); kept after, so the CRT is the last effect and
  SMAA cannot soften its scanlines.
- Shot harness broke: every 0.19 shot was black. Found by probes (a throwaway example):
  1. wgpu 29 reports `Occluded` for a hidden window and Bevy 0.19 then draws nothing to
     it (`bevy_render` `view/window`), so the [062] hide made the window empty. A
     `WindowOccluded` log showed `occluded=true` 0.03 s after start.
  2. A camera that targets an image with `ImageRenderTarget { scale_factor: 2.0 }` draws
     nothing in 0.19.1 (probe: green square on red at 1.0, all zero at 2.0; no error).
  Fix (`dev_tools.rs`): in a shot run the camera draws into a 625 x 625 image at scale 1
  (the window's logical size, so the world, UI and touch mapping stay as on the window),
  marked `IsDefaultUiCamera`, and the screenshot reads that image. The window still
  hides and the focus still goes back. Shots are now 625 x 625 (were 1250 x 1250).
  Dead ends: no CRT, plain camera, no focus give-back, no time pause, base plugins only:
  all still black (cause 2); the visible window at scale 2 renders fine, so players are
  not affected.
- Checks: `cargo build` and `cargo test` (32) pass; clippy: the same 9 old warnings.
  Shots (new 625 baseline `target/shots/019-*.png`): game and menu look the same as 0.18
  side by side (PSNR 31-32 dB against the 0.18 shots scaled down, from the resolution and
  CRT scanline pitch); Parley text sits where it was; seed 4 dies to the enemy; seed 10
  arrow near the same place ([026]). Bloom (now linear-space luma) looks the same.
- Not exercised: restart after game over (as in [014]). Pedro: one manual run, which also
  checks the real window on 0.19.

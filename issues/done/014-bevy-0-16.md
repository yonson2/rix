## Problem
Rix is on Bevy 0.15.3 (2025-02). The latest release is 0.20.1 (2026-10-28). Mobile fixes,
upstream iOS screen-edge support (D6) and current crates (avian, tooling) need a current
engine. First step of D3.

## Approach
Bump `bevy` to the latest 0.16.x and `avian2d` to the latest 0.3.x. Apply the official
migration guide (https://bevy.org/learn/migration-guides/0-15-to-0-16/) and avian's 0.3
changes; the checklist for Rix is in Notes. Change only what the step needs; leave
refactors to M3.

## Verification
`cargo build`, `cargo clippy --all-targets` (no new warnings) and `cargo test` pass;
`just shot` and `just shot-menu` look like the [013] shots; a manual run draws, claims,
dies to an enemy and restarts.

## Notes
- Done: bevy 0.16.1, avian2d 0.3.1 (last of each line). Lock kept winit 0.30.9, objc2
  0.5.2 (the [006] objc2 dev-profile override is still needed), android-activity 0.6.0
  (matches games-activity 2.0.2 for [021]; a broad `cargo update` would pull 0.6.1, which
  needs 4.4.0), wgpu 24.
- Applied (research checklist, 2026-11-02): `Commands::get_entity` returns `Result` (9
  sites) and `despawn` needs `&mut` (5 sites); `despawn_recursive` -> `despawn` (9);
  `get_single(_mut)` -> `single(_mut)` (4) and `Query::single` returns `Result`
  (`spawn_walls`); `EventWriter::send` -> `write` (24); `trigger.entity()` ->
  `trigger.target()`; `Parent`/`get()` -> `ChildOf`/`parent()`; `PickingBehavior` ->
  `Pickable`.
- avian `Collision` (one event per physics step while touching) is gone. The five readers
  (enemy + line -> Die, item + line -> activate, ball chaos, square gravity flip, arrow
  push) now read `CollisionStarted(e1, e2)` (one event when a contact starts), and
  `base.rs` requires `CollisionEventsEnabled` on every `Collider` (events are opt-in in
  0.3). Chosen because one event is all Die and items need, a bounce touched for about
  one step anyway, the old repeated events could flip the square's gravity twice in a
  frame, and avian 0.4+ continues with `CollisionStart`.
- Not needed (checked): `Smaa` path (the guide's `bevy_anti_aliasing` did not ship in
  0.16), `crt.rs` render graph API, shader imports, `Material2d`, `WindowResolution`,
  screenshot API, mesh paths in `shape.rs`.
- Checks: `cargo build` and `cargo test` (32) pass; clippy: the same 12 pre-existing
  warnings. New 0.15 references with [062] timing (`target/shots/062-*.png`): game shot
  14 px differ (PSNR 54.5 dB), Points 9 as before. Menu: 744 px differ (PSNR 41.5 dB), all
  on the edges of the neon-white "RIX" text and box stroke (mean 3.5/255 in the box);
  side by side they look the same (likely bloom or glyph raster changes in 0.16). Seed 4
  still dies to an enemy (so contact events with the body-less line segments work); seed
  10 still has the arrow at the same place.
- Not exercised: restart after game over (the harness does not tap on the game-over
  screen). Pedro: one manual run to confirm restart.
